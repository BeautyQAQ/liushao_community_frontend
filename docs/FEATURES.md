# 社区功能与运营指南

社区账号与后台账号是两套独立身份。社区注册页创建普通社区账号；后台账号、角色和权限仍在管理端「系统管理」中维护。管理端新增「社区运营」，通过服务端接口管理社区数据，浏览器不会收到内部连接密钥。

## 社区使用入口

| 入口 | 可用操作 |
| --- | --- |
| 首页主题列表 | 最新、近七天热门、精华和关注动态；置顶/精华标识；关注动态需要登录 |
| 草稿箱 | 查看、继续编辑、删除新主题及已有帖子的编辑草稿；草稿仅本人可见 |
| 帖子详情 | 评论、回复、删除自己的评论、点赞/取消、收藏/取消 |
| 我的帖子 | 查看公开、待审、隐藏状态及处理原因；修改或删除自己的帖子 |
| 我的收藏 | 分页查看收藏的公开帖子；隐藏或作者被禁用的内容不公开展示 |
| 用户主页 | 关注/取消关注、发私信；本人不能关注或私信自己 |
| 我的关注 / 我的粉丝 | 分页查看用户列表并进入主页或私信 |
| 通知中心 | 评论、回复、点赞、关注、审核通知；单条已读、全部已读、未读数 |
| 私信 | 会话列表、历史分页、发送文本、未读数、进入会话后标记收到的消息已读 |
| 个人设置 | 昵称、简介、头像上传、邮箱验证、修改密码 |
| 发帖编辑器 | PNG/JPEG 上传并插入 Markdown；预览和详情展示图片 |
| 登录 → 找回密码 | 邮箱验证码重置密码，成功后重新登录 |

评论回复显示一层关联，回复其他回复时关联到根评论。删除自己的根评论会同时删除回复；界面会要求确认。评论、私信按纯文本展示。Markdown 使用 HTML 清理；图片仅接受实际可解码的 PNG/JPEG，原文件不直接公开，重新编码后存储。单文件最多 4 MiB；大尺寸或处理后过大的图片会被拒绝。头像只能选择本人上传的图片。

首页「精华」只展示运营已加精且仍公开的主题；「关注动态」按发布时间展示当前账号关注的作者的公开主题，取消关注后不再展示。待审核、隐藏内容和停用作者不会进入这两类列表。选择的首页栏目会保留在地址中，刷新后仍停留在该栏目。

编辑器输入后自动保存草稿，也可点击「保存草稿」，未完成的标题或正文可以单独保存。草稿按账号存储，可从导航或「我的帖子」进入草稿箱继续编辑；每个账号最多保留 100 份。输入时同时保留当前浏览器的恢复副本，刷新或网络失败时可恢复尚未同步的内容；恢复副本按账号隔离，清除浏览器数据会移除仅保存在本机的副本。保存失败会明确提示，不会显示已同步成功。

发布前会先保存最新输入，成功发布或保存原帖后才移除对应草稿。草稿不会进入公开列表、搜索或标签计数。其他页面更新了同一草稿，或原帖已经变化时，旧页面不能覆盖新内容；当前输入会保留，可复制为新主题或确认后载入最新草稿。新帖及所有修改（包括已发布文章）提交后进入待审核，待审期间仅作者与管理端可见，审核通过后才公开。

点赞、收藏、关注是幂等操作，重复请求不会增加重复关系。通知和私信只对接收者/会话参与者开放，社区运营后台没有读取私人会话的接口。页面提供刷新操作，通知和私信在页面可见时定期刷新，无需保持 WebSocket 连接。

## 社区运营

管理员通过管理前端处理账号、内容审核和运营资源；操作按角色权限校验并保存审计。页面、权限及审核流程见 [管理端运营指南](../../authority_management_frontend/docs/COMMUNITY_OPERATIONS.md)。

## 开发配置与数据

- 两后端配置相同、独立随机的 `COMMUNITY_ADMIN_KEY`（至少 32 字符）；管理后端配置 `COMMUNITY_API_URL`。本地默认为 `http://localhost:8080`，Compose 中为 `http://community-api:8080`。密钥未配置时运营接口拒绝访问。部署工具 `liushao_community_backend/deploy/scripts/init-deploy.py` 会生成该密钥；已有部署配置需要补上。
- 邮件配置为 `SMTP_HOST`、`SMTP_PORT`、`SMTP_USERNAME`、`SMTP_PASSWORD`、`SMTP_FROM`、`SMTP_AUTH`、`SMTP_STARTTLS`。默认启用认证和 STARTTLS，须使用实际 SMTP 服务的参数。未配置邮件服务时，发送接口会明确返回服务未配置；不会返回验证码或伪装发送成功。开发验收使用本机隔离 SMTP 收件服务。
- 邮箱验证码有效期 10 分钟、最多尝试 5 次、使用一次失效；同用途重发间隔 60 秒，并限制来源 IP 频率。找回密码响应不确认邮箱是否存在。主动修改或重置密码都会使旧登录及旧邮件验证码失效；验证码和密码不会写入应用日志。
- 上传目录由 `UPLOAD_DIRECTORY` 指定，默认 `./data/uploads`，Compose 使用独立持久卷 `community-uploads`。数据库备份只包含图片元数据，恢复完整内容还必须备份和恢复上传目录。
- Flyway 增量：管理端 V2 增加社区菜单权限与内置菜单标识；社区端 V2 增加互动、关注、通知、私信与运营结构，V3 增加邮件验证码与上传元数据，V4 增加私有草稿，V5 保存历史社区 ID 映射，V6 将新帖默认状态改为待审核（保留已有公开文章的状态）。两端共用 `liushao_community`，使用独立历史表。已有迁移保持不变；历史数据转换结果见 [迁移记录](../../liushao_community_backend/docs/legacy-community-migration.md)。

正式环境的域名、TLS、镜像发布和自动部署继续留到最后。运行与备份说明见 [DEPLOYMENT.md](../../liushao_community_backend/deploy/README.md)，实施验证结果见 [MODERNIZATION.md](../../liushao_community_backend/docs/archive/WORKSPACE_HISTORY.md)。
